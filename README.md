# My Next.js Portfolio

This is a personal portfolio website built with Next.js to showcase my skills, projects, and experience.

### Features
* **Home Page:** A welcome screen with a background image, a brief introduction, and a navigation bar.
* **About Section:** A page sharing my background, profile picture, and key programming skills.
* **Projects Section:** A grid displaying my coding projects. It reads data from a local JSON file using Next.js `getStaticProps`.
* **Contact Section:** A working contact form that securely handles messages using Next.js API routes.
* **Fully Responsive:** The layout adjusts perfectly for mobile phones, tablets, and desktop computers.

### Technologies Used
* **Next.js (Pages Router)**
* **React**
* **CSS Modules** (for styling)

### How to Run the Website
1. Open your terminal inside the project folder.
2. Run `npm install` to download all the necessary files.
3. Run `npm run dev` to start the local server.
4. Open `http://localhost:3000` in your web browser to view the site.
